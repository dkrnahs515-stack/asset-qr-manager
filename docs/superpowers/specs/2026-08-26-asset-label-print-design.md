# 강서청소년회관 QR 비품 라벨 자동출력 설계

작성일: 2026-08-26  
대상 브랜치: `feature/asset-label-print-pilot`

## 1. 목표

Google Sheets의 비품·QR 데이터를 기반으로 Formtec LS3106 라벨을 선택 출력할 수 있는 전용 작업 흐름을 구현한다.

사용자는 `라벨출력` 시트에서 비품을 체크하고, 선택한 비품을 24개씩 자동 분할한 A4 미리보기를 브라우저에서 확인한 뒤 `인쇄 / PDF 저장`을 실행한다. 실제 출력이 정상적으로 끝난 뒤에만 `출력 완료 반영`을 눌러 `QR발급관리`의 발급·재출력 이력을 갱신한다.

## 2. 범위

이번 단계의 포함 범위는 다음과 같다.

- `라벨출력` 전용 시트 생성 및 새로고침
- 체크박스 기반 출력 대상 선택
- 비품번호·품명·위치·QR 상태·재출력 상태 확인
- 층 → 공간 → 비품번호 순 정렬
- 24개 단위 A4 페이지 분할
- 브라우저 A4 라벨 미리보기
- 인쇄 또는 브라우저의 PDF 저장
- 최초출력/재출력 구분
- 출력 완료 시 QR 발급관리 이력 갱신
- 동일 배치 재실행에 대한 멱등 처리
- TEST/PRODUCTION 표시 차등
- 좌표·QR·출력상태·오류처리 자동 테스트

이번 단계에서 제외한다.

- 서버에서 PDF 파일을 직접 생성해 Google Drive에 저장하는 기능
- `라벨출력` 화면에서 신규 QR 접근키를 자동 발급하는 기능
- 운영 842개 전체 라벨의 실제 일괄 발급·부착

## 3. 기존 데이터 소스

### `비품마스터`

출력 대상 비품의 기준 원장이다.

주요 필드:
- 영구 시스템 ID
- New 비품번호
- 품명
- 층
- 공간명
- 사용여부
- QR조회URL

### `비품현재상태`

현재 위치와 최근 조사 정보를 제공한다.

주요 필드:
- 영구 시스템 ID
- 현재층
- 현재공간명
- 현재조사결과
- 최근판정일시

### `QR발급관리`

활성 QR과 인쇄 이력의 기준 원장이다.

주요 필드:
- 영구 시스템 ID
- QR접근키
- QR접근키상태
- QR조회URL
- QR발급상태
- 라벨유형
- 라벨버전
- 인쇄책임자 정
- 인쇄책임자 부
- 책임자버전
- 라벨기준조사일
- 최초발급일시
- 최종출력일시
- 재출력필요여부
- 재출력사유
- 재출력횟수
- 최종출력배치ID

### `위치마스터`

출력 순서를 결정하는 표준 위치 기준이다.

주요 필드:
- 위치코드
- 층
- 공간명
- 모바일정렬순서

### `라벨설정`

라벨 디자인과 프린터 보정값의 기준이다.

확정값:
- 기본 라벨규격: `FORMTEC_LS3106`
- 라벨가로: 64mm
- 라벨세로: 33.9mm
- 페이지열수: 3
- 페이지행수: 8
- 페이지왼쪽여백: 6.5mm
- 페이지위쪽여백: 12.5mm
- 열간격: 2.5mm
- 행간격: 0mm
- QR크기: 20mm
- 가로보정: -1.8mm
- 세로보정: +2.7mm
- 3열가로보정: +0.3mm
- 인쇄배율: 100%
- 관리책임자 정: 김은영
- 관리책임자 부: 김정훈

## 4. `라벨출력` 시트 설계

`라벨출력`은 원장이 아니라 출력 작업을 위한 파생 작업화면이다.

| 열 | 항목 | 역할 |
|---|---|---|
| A | 출력선택 | 체크박스 |
| B | 출력구분 | 최초발급 / 재출력 자동 표시 |
| C | New 비품번호 | 라벨 표기용 |
| D | 품명 | 라벨 표기용 |
| E | 현재층 | 비품현재상태 기준 |
| F | 현재공간명 | 비품현재상태 기준 |
| G | 현재조사결과 | 정상·위치변경·상태이상·미발견 등 |
| H | QR상태 | 사용 / 중지 |
| I | QR발급상태 | 미발급 / 발급완료 / 재발급필요 |
| J | 재출력필요 | Y / N |
| K | 최근조사일 | 라벨 조사 일자 |
| L | 출력가능여부 | 출력가능 또는 사유 |
| M | 영구 시스템 ID | 내부용, 숨김 |
| N | QR조회URL | 내부용, 숨김 |
| O | 위치정렬순서 | 내부용, 숨김 |

상단에는 검색·층·공간·출력상태 필터와 함께 `선택 N개 · 예상 M페이지`를 표시한다.

### 버튼/메뉴

- 목록 새로고침
- 현재 필터 전체선택
- 선택해제
- 재출력 대상 선택
- 선택 라벨 미리보기

동일 기능은 Google Sheets 사용자 메뉴 `QR 라벨`에도 제공한다.

## 5. 출력 대상 규칙

라벨출력 화면에서는 QR을 새로 발급하지 않는다.

출력 가능 조건:

1. `비품마스터.사용여부 = 사용`
2. `QR발급관리`에 `QR접근키상태 = 사용`인 행이 정확히 1개 존재
3. QR 접근키가 유효한 32자 URL-safe 키
4. QR조회URL이 활성 접근키와 일치
5. New 비품번호와 품명이 존재

다음은 출력불가 처리한다.

- 활성 QR 없음
- 활성 QR 2개 이상
- 중지 QR만 존재
- QR URL 누락 또는 접근키와 URL 불일치
- 비품마스터에 없는 시스템 ID
- 사용 중지 비품

출력구분 자동 규칙:

- 활성 QR + QR발급상태 `미발급` → `최초발급`
- `재출력필요여부 = Y` 또는 QR발급상태 `재발급필요` → `재출력`

## 6. 출력 정렬 규칙

사용자가 체크한 순서와 관계없이 미리보기는 자동 재정렬한다.

우선순위:

1. 현재 위치의 `위치마스터.모바일정렬순서`
2. 현재층
3. 현재공간명
4. New 비품번호

현재 위치가 위치마스터와 매칭되지 않는 경우에는 마지막 그룹으로 보내고 층·공간명·비품번호 순으로 정렬한다.

## 7. 페이지 분할

- 용지: A4 210 × 297mm
- 한 페이지: 3열 × 8행 = 24개
- 1~24개: 1페이지
- 25~48개: 2페이지
- 49~72개: 3페이지
- 마지막 페이지의 남는 칸은 공백 유지

## 8. 브라우저 미리보기 구조

`선택 라벨 미리보기`를 실행하면 클라이언트에서 화면 셀 값을 그대로 사용하지 않고, 선택된 영구 시스템 ID 목록만 서버에 전달한다.

서버는 최신 데이터를 다시 읽어 출력 모델을 만든다.

데이터 흐름:

`선택 영구 시스템 ID` → `비품마스터` 검증 → `비품현재상태` 조합 → `QR발급관리` 활성 QR 검증 → `위치마스터` 정렬 → `라벨설정` 좌표 계산 → 24개 단위 페이지 모델 → HTML 미리보기

미리보기 상단 제어바 예:

`선택 53개 · 3페이지 · Formtec LS3106`

버튼:
- 인쇄 / PDF 저장
- 출력 완료 반영
- 닫기

## 9. 인쇄 좌표 계산

좌표는 코드에 최종값을 하드코딩하지 않고 `라벨설정`을 읽어 계산한다.

기본 계산:

- 1열 X = 왼쪽여백 + 전체가로보정 = 6.5 - 1.8 = 4.7mm
- 2열 X = 1열 X + 64 + 2.5 = 71.2mm
- 3열 X = 2열 X + 64 + 2.5 + 0.3 = 138.0mm
- 첫 행 상단 Y = 위쪽여백 - 세로보정 = 12.5 - 2.7 = 9.8mm
- 다음 행은 33.9mm씩 증가

3열 전용 +0.3mm 보정은 모든 행의 3열에 적용한다.

## 10. 라벨 디자인

최종 디자인:

- 외곽 검은 테두리 없음
- QR 왼쪽 배치
- QR 크기 20mm
- 조사 일자는 QR 아래 중앙 정렬
- 비품번호 오른쪽 상단
- 품명은 비품번호와 동일한 9.3pt 기준
- 긴 품명은 가용 폭에 맞춰 자동 축소
- `관리책임자` 문구 표시
- 아래 줄에 `정 김은영 · 부 김정훈` 약 9pt
- 내부 옅은 구분선 유지
- TEST 환경: `TEST PILOT` 표시
- PRODUCTION 환경: TEST 문구 미표시

조사 일자:

- `비품현재상태.최근판정일시`의 날짜 부분 우선
- 최근판정일시가 없으면 `미조사`

## 11. QR 렌더링

외부 QR API를 사용하지 않는다.

브라우저에 포함한 QR JavaScript 라이브러리로 `QR조회URL`을 SVG QR로 렌더링한다.

이유:
- 외부 서비스 장애 비의존
- QR 접근키 외부 전송 방지
- 인쇄 시 벡터 품질 유지

QR 데이터는 `QR발급관리`의 현재 활성 QR조회URL만 사용한다.

## 12. 인쇄 및 PDF 저장

미리보기에서 `window.print()`를 실행한다.

인쇄 CSS:

- `@page { size: A4; margin: 0; }`
- 페이지는 210 × 297mm 고정
- 화면 제어바는 print media에서 숨김
- 불필요한 배경·스크롤 요소 제거

사용 안내:

- 배율 100%
- 실제 크기
- 여백 없음
- 머리글/바닥글 끄기

사용자는 브라우저 인쇄창에서 실제 프린터 또는 `PDF로 저장`을 선택한다.

## 13. 출력 완료 반영

미리보기를 생성하거나 인쇄창을 열었다는 이유만으로 발급완료 처리하지 않는다.

실물 라벨 출력이 정상 확인된 뒤 사용자가 `출력 완료 반영`을 눌러야 한다.

출력 배치 ID 형식:

`LABEL-YYYYMMDD-NNN`

예:

`LABEL-20260826-001`

반영 항목:

- QR발급상태 = 발급완료
- 라벨유형 = FORMTEC_LS3106
- 라벨버전
- 인쇄책임자 정
- 인쇄책임자 부
- 책임자버전
- 라벨기준조사일
- 최종출력일시
- 최종출력배치ID

재출력인 경우 추가 처리:

- 재출력횟수 +1
- 재출력필요여부 = N
- 재출력사유 유지 또는 완료 시점 정책에 따라 별도 이력 보존

## 14. 멱등성 및 중간 실패 복구

같은 출력배치ID에 대해 `출력 완료 반영`이 여러 번 호출되어도 동일 비품의 재출력횟수나 최종출력 상태를 중복 증가시키지 않는다.

완료 처리 전 서버에서 QR 활성 상태를 다시 검증한다.

대량 처리 중 일부 쓰기 실패가 발생하면:

- 이미 같은 배치ID가 반영된 행은 건너뜀
- 미반영 행만 다시 처리
- 최종 결과에서 성공·실패 시스템 ID를 구분하여 반환

## 15. 오류 처리

미리보기 대상 중 하나라도 출력불가 항목이 있으면 해당 항목을 조용히 제외하지 않는다.

전체 미리보기를 중단하고 다음 정보를 표시한다.

- 요청 개수
- 출력 가능 개수
- 출력 불가 개수
- 비품번호
- 영구 시스템 ID
- 실패 사유

예:

`24개 중 2개 출력 불가 — GSYC-000123: 활성 QR 없음 / GSYC-000456: QR URL 불일치`

사용자가 데이터를 수정한 뒤 다시 미리보기를 생성한다.

필수 테스트:

1. 층·공간·비품번호 정렬
2. 위치마스터 모바일정렬순서 우선
3. 1~24개 = 1페이지
4. 25개 = 2페이지
5. 49개 = 3페이지
6. 1·2열은 공통 보정만 적용
7. 3열은 +0.3mm 추가 적용
8. 전체 X -1.8mm / Y +2.7mm 계산
9. 활성 QR 없음 차단
10. 활성 QR 중복 차단
11. 중지 QR 차단

## 18. 시트 갱신 정책

`라벨출력` 시트는 `목록 새로고침` 시 원장 데이터를 다시 읽고 재작성한다.

체크박스 상태는 새로고침 시 초기화한다.

원장 역할을 하지 않으므로 다음 정보는 절대 `라벨출력` 시트만 보고 판단하지 않는다.

- 활성 QR 여부
- QR URL
- 발급 상태
- 현재 위치
- 최근 조사일

미리보기 직전에 서버가 원장을 재검증한다.

## 19. 보안 원칙

- QR 접근키는 시트 내부에서만 읽고 외부 QR API로 전송하지 않는다.
- 클라이언트에서 전달된 URL·상태값을 신뢰하지 않는다.
- 서버는 영구 시스템 ID를 기준으로 원장을 재조회한다.
- 중지 QR은 출력하지 않는다.
- 출력 완료 반영은 Script Lock으로 동시 쓰기를 보호한다.
- TEST와 PRODUCTION 환경 분리는 기존 RuntimeConfig 정책을 따른다.

## 21. 성공 기준

다음이 모두 만족되면 기능 구현 완료로 판단한다.

- 사용자가 `라벨출력` 시트에서 안전하게 대상 선택 가능
- 잘못된/중지/중복 QR은 미리보기 전에 차단
- 선택된 비품이 위치 기준으로 올바르게 정렬
- 24개 단위로 정확히 페이지 분할
- 확정된 LS3106 보정값과 3열 +0.3mm가 미리보기에 반영
- 최종 라벨 디자인이 기존 실물 테스트 디자인과 일치
- 브라우저에서 100% 크기로 인쇄/PDF 저장 가능
- 출력 완료 전에는 QR발급관리 상태가 변경되지 않음
- 출력 완료 후 발급/재출력 이력이 정확히 기록
- 동일 배치 재호출 시 중복 증가 없음
- 기존 시스템 기능과 테스트가 깨지지 않음
